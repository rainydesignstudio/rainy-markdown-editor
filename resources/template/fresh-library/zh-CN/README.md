# Rainy 文稿台资料库

先核对文稿台的运行版本。优先复用用户指定、会话上下文或相关文档中已明确的同版本本地项目或手册副本。

缺少同版本手册时，从 [官方发布列表](https://github.com/rainydesignstudio/rainy-markdown-editor/releases) 找到对应标签，选定资料库外的完整保存路径，先问用户：

> 开始工作前，我需要从官方仓库拉取这版的人机共用说明书，存到 `<完整路径>`，以后可以直接复用。你同意吗？

用户同意后，再创建目录并拉取仓库根 `README.md` 和 `docs/locale/` 下的中英文说明书。保留仓库目录结构，记下发布标签和本地路径，供后续会话复用。已有的同版本副本或同范围授权可直接沿用。

从本地 `docs/locale/zh-CN/AGENT-GUIDE.md` 开始，读完本任务的必读章节，再核对本库实际生效的格式配置、样式与校验规则。缺少必读手册时，先获得拉取许可或找到可用副本，再动笔。

每个新会话只在首次接手资料库时问一次「要不要改用本地部署？」用户已有明确选择就沿用。等待部署答复期间，照常查阅手册并推进当前任务。

- 继续用官网时，从本地手册副本查阅。
- 用户选择本地部署且无已知项目时，从官方仓库拉取对应版本的完整项目，启动应用，从项目内查阅手册。
- 用户选择本地运行且已有明确的项目路径时，复用该项目，按对应版本的说明启动，从项目内查阅手册。
