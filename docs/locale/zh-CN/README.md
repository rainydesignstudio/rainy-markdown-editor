## ✨ 功能与特性

| 功能 | 说明 |
|---|---|
| 🗂️ **外置资料库** | 编辑器主题、文章主题、片段、起稿模板、文章、历史记录，甚至是格式清单、校验和排版策略，都按资料库解耦，一个资料库就是另一个世界。 |
| 💾 **纯本地管理** | 文章资料在本机浏览器中处理，即使通过在线页面使用，管理的也是你自己的本地资料库。 |
| 👁️ **真渲染预览** | 左侧写源码，右侧看预览；预览、复制与可视导出共用渲染和格式处理流程，排版与图片都能先在本地核对。 |
| 🎨 **主题自定义** | 编辑器主题控制工作台；文章主题按资料库选择算法只读深色或可编辑的深色token覆盖。 |
| 🧩 **模板随心建** | 用起稿模板组织文章，用片段复用提示卡、章节等内容，后者只要在文中输入 `//` 即可快捷插入。 |
| 🗃️ **分组与归档** | 按项目、分类和年月整理文章，支持归档、Fork 和历史快照，还可为文章设置分类，方便二级查找。 |
| 🖼️ **内置素材库** | 统一管理共享/文章图片与附件：类型筛选、搜索、排序、多选、移动/复制、改名、描述和删除；图片保留替换、缩放预览。 |
| ⚙️ **外置检测器** | 每个资料库各用一套规范、validator 与 formatter；平台规则、换行、预览背景和转换策略在 JSON 中配置。 |
| ✅ **格式检查** | 在撰写时提示格式和本地图片问题；保存与复制前仍会提供独立检查结果，方便查看哪里还要改。 |
| 🌐 **中英界面** | 切换语言保留草稿、查找替换和已有报告；日期、数量与公告按界面语言显示，资料库内容保持原文。 |
| 📦 **文档导出** | 保存文稿，导出文档包、Markdown、长图片或 PDF；具体入口以应用中的导出菜单为准。 |
| 🔗 **只读知识库** | 连接独立知识源，主动扫描、内容搜索、关系图与可编辑副本导入。 |
| 📥 **Markdown 导入** | 主题预选可换，正文先建档、资源后台复制，支持暂停、重试与补选。 |
| 🧮 **公式与图** | 可选本地公式/静态 Mermaid 渲染，源码保持，输出按目标平台核对。 |

现有内置内容包含 7 套文章主题、11 套编辑器主题、21 个片段和 5 个起稿模板。也可以制作自己的内容。

文稿信息中按 Enter 或“应用目录名”立即更新索引、项目及排序记录并重读文稿。合法中文逗号、句号与全角标点按输入保留；路径分隔符、保留字符与重名会被拒绝。信息标题和源码栏显示目录名，正文文件仍叫 `article.md`。成功由工具栏下方的全局提示显示“目录已修改”，3秒消退；弹窗不再保留结果行，失败原因可手动关闭。

本地图片“查看与改名”窗口用普通滚轮上下看长图，Ctrl/⌘＋滚轮缩放；图片框底部居中按钮可缩小、放大或恢复适应宽度。

<a name="doc-run-yourself"></a>

### 💻 自己启动

准备 Git、Node.js 24 LTS（含 npm）和桌面浏览器。本项目统一使用 npm，依赖由 `package-lock.json` 固定。macOS 的 Arc 已用于本地目录和剪贴板走查；浏览器需要提供 File System Access 目录授权能力，桌面 Chrome／Edge 是应用建议入口。其它系统／浏览器组合的实际目录和剪贴板行为需自行确认。

获得源码后，在项目目录安装依赖、构建并启动：

```sh
npm install
npm run build
npm start
```

打开终端打印的本机地址，并保持服务运行。

默认地址为 `http://127.0.0.1:3500`。需要其它端口时用 `npm start -- --port 3501`（替换为已确认端口）；启动帮助用 `npm start -- --help`。端口占用时服务退出，不会自动结束已有进程。

构建完成后，后续在同一项目目录执行 `npm start` 即可启动。源码更新后重新安装所需依赖、构建并重启。启动脚本会复用已有的 `out/` 静态产物；缺少 `out/index.html` 时明确提示先执行 `npm run build` 并退出，不会隐式构建。

微信复制的引用保留主题样式并输出为 `section`；生成的预览外壳不携带默认页边距或宽高限制，正文内部间距保留。旧稿采用当前库策略前，点编辑页顶栏循环箭头“更新样式”（“导出文章”之后、“检查格式”之前），再复制到接收区核对，并到公众号复验。见[复制输出配置](FORMAT.md#doc-copy-output)。

<a name="doc-font-downloads"></a>

### 字体下载与离线使用

在“设置 → 本地目录 → 字体下载来源”中选择来源；连接或创建资料库前也能设置。默认 Google Fonts，国内可选免费“国内镜像（JSDMirror）”，无需购买 CDN。偏好保存在当前浏览器来源内，不按语言或地区自动切换。

应用和新构建不携带 Sen、Noto Sans SC、Roboto Mono 的完整 TTF。初始化只补 `fonts/` 缺失文件，下载核对大小与 SHA-256 后才写入；已有字体和自定义文件保持。每个文件30秒超时，失败回退系统字体，资料库其余加载继续。可在同一区域点“补充缺失字体”，或换源后重试；下载期间可取消。

完整文件保存在资料库后可离线读取。安装和构建无需预取字体，首次补充时浏览器需能访问 `raw.githubusercontent.com` 或 `cdn.jsdmirror.com`；下载直接访问所选来源，不经过官网服务器。身份、版本、字重、许可及固定 URL 统一见 [字体来源清单](../../../resources/font-sources.json)。部署需允许浏览器通过 HTTPS 连接所选来源，字体本身仍由授权资料库加载。

<a name="doc-first-use"></a>

## 🌱 第一次使用

1. 打开“设置 → 本地目录 → 新建资料库”，输入资料库文件夹名称，选择校验与算法模板（当前为“微信公众号”），然后选择父目录并授权读写。应用会创建一个命名子目录；同名目录已存在时，请改名或使用“打开已有资料库”。
2. 已有资料库直接使用“打开已有资料库”，选择资料库本身。应用只记住最后一个目录书签；权限失效时需重新授权。
3. 新建文章，输入正文并保存（macOS `⌘S`，其它系统 `Ctrl+S`）。文章目录和主题快照在保存时生成。
4. 在“主题”中试看文章主题。已保存文章使用“复制并应用”，生成副本并保留原稿和主题快照；未保存新稿使用“应用到当前稿”。
5. 在“模板”中管理片段和起稿模板；在编辑器里通过“插入元素”或输入片段触发词采用。
6. 在“素材”中导入共享/文章图片与附件。也可把本地文件拖入素材页，核对目标库、文件清单及格式后确认；取消不写入。采用共享图片会复制到文章自己的 `media/image/`；共享原件与文章副本独立。
7. 可选连接[只读知识源](#doc-knowledge)，主动扫描后浏览、搜索或从图谱打开文档。
8. 可选[导入 Markdown](#doc-markdown-import)，正文先建档，资源在后台取得；失败项在任务窗恢复。
9. 复制富文本，先在剪贴板接收区核对；回到公众号编辑页由使用者手动粘贴，并检查草稿和手机预览。 接收区使用当前资料库的浅色纸面，保留粘贴内容原色；文章深色预览不改变这里的底板。

窗口窄时可切换源码／预览。目录授权、素材操作和公众号编辑以桌面浏览器为主要使用场景。

<a name="doc-preview-controls"></a>

### 👁️ 文章预览操作

预览标题栏的三个图标从左至右如下，悬停或键盘聚焦可查看提示；偏好按浏览器来源记住。

| 控件 | 默认 | 行为 |
|---|---|---|
| 预览滚动对齐 | 关闭 | 源码顶端对应的已渲染元素对齐预览顶部；只从源码联动预览。 |
| 保存时显示格式检查 | 开启 | 手动保存后显示报告；关闭只省略弹窗，自动保存不弹窗。 |
| 仅保存时刷新预览 | 关闭 | 编辑时保留可见正文、主题及样式；成功保存编译后刷新，显式采用不同或更新后的主题成功时也刷新一次；开启时源码底部显示“保存刷新预览”，关闭恢复实时。 |

冻结画面不替代当前稿检查、复制或导出。留存画面也能滚动联动：仅对齐仍可对应的内容，插删处采用最近有效节点，没有对应节点时保留位置；复制若沿既有流程先保存未保存稿件，也会刷新画面。格式检查、原文保存和渲染记录失败分别反馈，不把留存画面或未完成检查视为通过。

<a name="doc-source-formatting"></a>

### ⌨️ 行内格式快捷键

在文章正文源码中按 `Cmd/Ctrl + B`、`Cmd/Ctrl + I`、`Cmd/Ctrl + U`，分别加粗、斜体和下划线；“插入元素 → 文字格式”右侧显示相同键位。选中文字会保留选区内容，空选区只插入成对标记；再次执行可取消直接包围选区的标记。普通Markdown使用对应Markdown标记，HTML段落文字使用HTML行内标签。

菜单和快捷键共用一次可撤销编辑，撤销/重做仍按当前输入框的焦点区分。输入法组合、只读或不可编辑状态不执行格式操作，查找/替换框的文字不会被改写。

图片地址为空或链接/解码失败会明确报错；已失败图片不再重复等待超时。加载中的资源仍不算检查通过，修复后点击格式检查重检。

<a name="doc-interface-language"></a>

### 🌐 界面语言

左下版本号下面可选择“简体中文”或“English”。首次按浏览器语言匹配，手动选择按当前浏览器来源记住；不同主机名、端口或浏览器分别保存。语言只改变产品界面、提示、诊断和日期／数字展示，不翻译文章、库内名称、片段／模板正文或自定义规则文案，不保存或重编译文章。编辑器主题和文章预览明暗仍各用原偏好。

默认回退英文：已保存的手选优先，其次按浏览器受支持语言匹配，未匹配时使用英语。新资料库提供中英两套完整默认内容，创建时选择中文界面即采用中文种子，其余采用英文。种子语言记在 `themes/default-themes.loaded` 的 `locale`（`zh-CN`／`en-US`）；空目录补齐与“载入默认主题”沿用该记录，缺记录的旧库采用英文默认且不重写原文件。之后切界面语言不翻译或补入另一语种内容。

### 🗃️ 文章列表、分类与检查

列表从月索引读取摘要，打开文章时再读取该篇正文和主题快照。全部文章、未分组与项目显示未归档文章；归档单独显示。分类来自当前集合。

“检查当前范围”检查当前搜索、年月及分类筛选后的文章，可查看进度或取消。汇总按篇计数；未检测、需重检和检查失败分别显示。记录只在当前资料库会话复用，表示上次检查结果；修改正文、主题或格式配置后需重新检查。

分类左侧的多选图标进入标签管理。勾选要移除的标签，再确认当前筛选范围和受影响篇数；操作只移除文章中的这些标签。归档分类可筛选，移除标签需先取消归档。

外部直接修改文件后，在列表的索引修复入口主动扫描并重建。旧索引缺字段或索引损坏时会提示列表可能不完整；重建读取提示中的年月，保留原稿及损坏文章的诊断。仅“刷新”会重新读取索引，不会扫描全部正文。

<a name="doc-knowledge"></a>

## 🔗 只读知识库

1. 先连接可读写的文稿资料库，再在“知识库 → 连接知识源”选择独立目录，仅申请读取。两个目录不能相同或互相包含。
2. 首次点“扫描更新”建索引；后续增量更新只重新解析变化的文档。日常搜索和图谱读索引，选中文档时才读取原件。文件大小/修改时间未变化但内容已改时，使用“强制重建”。扫描失败或取消保留有效旧索引；页面显示扫描时间及缺失、歧义和未完成项。
3. 可读 Markdown 链接和 `[[路径或唯一文件名|别名]]`；代码、公式和 Mermaid 源码中的示例不计关系。全局/局部图支持筛选、定位、拖动和缩放，双击节点或 Enter 打开只读文档。
4. 选中文档点“导入为文稿”，创建可编辑副本并选文章主题。知识源始终只读；导入资源、索引和任务记录都写到文稿资料库。

本版每库一个知识源，最多索引10000篇、每篇2MiB；大图最多显示300节点/2000连线，裁切会提示，可筛选或改用局部图。索引包含可搜索的源文内容；备份文稿资料库时同时包含它。知识原件需另行备份。

## 📥 导入 Markdown 与资源

在文章页点“导入 Markdown”，选择 UTF-8 的 `.md` 或 `.markdown` 文件（上限2MiB）。默认预选资料库的默认文章主题，可换选；导入会新建文稿和独立主题快照，保留未知 Front Matter 字段，规范目标日期、分类和主题绑定。

仅选单文件不会授权旁边的资源。需要本地资源时，在导入窗另选包含该文件的源目录并授权只读。正文和资源原件保留；应用先为新稿分配最终资源名和引用，再后台逐件复制。HTTPS 图片和明确附件链接会尝试直接取得，受 CORS/CSP 约束，不发送登录凭证、不借第三方代理。私网、可执行协议、需认证或跨域受限资源会失败，可补选本地文件。

Markdown 图片、明确附件及 HTML img/srcset/SVG image、音视频 source 等引用纳入迁移。普通网页、其它笔记不递归下载；CSS 背景/字体和复杂嵌入不自动迁移，会提示保留的未迁移内容。资源能保存不保证内嵌 SVG/音视频或目标平台支持其显示；非栅格附件可在素材库管理、采用和下载。

<a name="doc-import-tasks"></a>

### ⏳ 后台任务与恢复

- 正文先出现，编辑、撤销和保存可继续；资源并发2、按块传输，底部显示进度，到账只更新资源和任务，不回写旧全文。
- “导入任务”可查看失败原因、暂停/取消、重试、补选源文件/源目录或替代资源。同库切稿继续，切库/失权暂停，删除目标取消；关闭页面后不继续运行，重开后需手动重试，不承诺网络字节续传。
- 恢复会核对来源、目标和已有文件。无法确认的同名文件保留并报冲突，不覆盖；新选择的替代资源会记录来源。任务记录保存失败时保留已建文稿并提示重试。
- 图片继续使用 `media/image/`、`/shared/image/`；其它文件使用 `media/file/`、`/shared/file/`，一般附件上限64MiB，图片沿用既有格式/大小限制。23类文件图标、类型筛选和未知文件回退共用素材管理；仅支持的栅格图片自动预览，SVG、PDF、音视频和其它附件不自动执行或预览。
- 拖入/选择文件先确认文件清单和目标，取消不写入。采用共享素材会复制独立文稿资源；改名更新当前引用并保留历史所需原件，删除前核对引用。
- 校验区分导入中、失败和缺失，未完成不算通过。文档包含文章媒体及明确引用的共享资源，不带知识索引/来源缓存/任务；无法携带项须明确确认后才输出部分包，原引用保持。内存打包上限256MB。

## 🧮 公式与 Mermaid

这两项是资料库 `formatter.steps[]` 的可选能力，旧库和默认未启用配置继续原行为；按 [FORMAT.md](FORMAT.md#doc-source-rendering) 的示例启用。

公式支持行内 `$x^2$`、块公式和 `math` 代码块，使用本地 KaTeX 生成静态 MathML。Mermaid 支持流程、时序、状态、类和实体关系图，以隔离帧生成静态 PNG；配置指令、交互和外部资源不执行。源码保留在 Markdown，坏源码保留并给诊断。

图生成完成后再复制或导出；未完成占位不会保存为渲染/历史成品，原稿保存独立，完成后可再保存或更新样式。MathML可能被目标平台移除或改写；图片的粘贴/发布效果也需核对，必要时用 PNG/PDF。深浅、窄宽、实际浏览器及接收方验证各自记录。

## 💾 资料库与备份

下面是使用过程中陆续生成的结构，目录和文件随实际操作出现：

```text
资料库/
├── settings.json                    # 保存工作流、组织及外观后生成
├── format/                          # 新库生成一套配置
│   ├── format-support.json
│   ├── validator.json
│   └── formatter.json                # steps[]
├── fonts/                           # 预设本地字体与原许可文件
├── themes/
│   ├── article-themes/<id>.json
│   └── editor-themes/<id>.json
├── snippets/
│   ├── index.json                    # 分类索引
│   └── <分类>/<id>.json
├── templates/
│   ├── index.json
│   └── <分类>/<id>.md
├── articles/YYYY-MM/
│   ├── index.json                    # 可重建月索引
│   └── <文章目录>/
│       ├── article.md
│       ├── theme.json                # 文章独立主题快照
│       ├── media/image/              # 文章图片及可选描述索引
│       ├── media/file/               # 附件及index.json描述，按需生成
│       ├── render.json              # 可选渲染成品与依赖引用
│       └── history/snapshot-…/       # 源码、主题、清单与可选渲染记录
├── styles/                          # 可选库级CSS及不可变渲染版本
│   ├── globals.css
│   └── .versions/<hash>/manifest.json
├── assets/                          # 库级图片/SVG/字体，按需出现
│   ├── image/
│   ├── fonts/
│   └── .objects/<hash>              # 历史引用的资源对象
├── shared/
│   ├── image/                       # 共享图片，按需生成
│   └── file/                        # 共享附件，按需生成
├── knowledge/                      # 只读源的绑定和索引，写在此库
│   ├── binding.json
│   └── index/manifest.json          # 分片在index/generations/
└── imports/tasks/<id>.json          # 独立资源任务
```

新建流程创建顶层目录及格式三件套，文章目录为空，随后加载内置主题、片段和模板，并从所选外部源补齐缺失的完整字体，原许可文件随应用提供。新库没有 `settings.json` 时先使用默认值，明确保存设置后再写入。旧布局迁移保留原文件，主题子目录可能包含迁移标记。

**代码目录与资料库分开备份。** 文章源码、元数据和主题快照随文章保存，图片和附件随完整文章目录保留。历史快照不包含媒体文件的完整备份，也不能替代整库备份。

定期将整个资料库复制到独立位置，并抽查文件可读；恢复前保留现有资料副本。月索引是缓存，重建索引不等于恢复丢失的正文。仓库忽略的 `data/`、浏览器书签和 `out/` 都不应被误当作资料备份。

## ❓ 常见问题

| 现象 | 处理 |
|---|---|
| 启动端口占用 | 换一个已确认可用的端口，或由使用者处理已有服务；不要自动结束不明进程 |
| 界面仍是旧版本 | 源码更新后重新构建，重启静态服务并刷新浏览器 |
| 目录权限失效 | 在“设置 → 本地目录”重新打开原资料库并授权 |
| 切换端口后找不到已记住的资料库 | 不同地址属于不同浏览器来源，需重新选择目录；磁盘文件仍在 |
| 源码有图片引用，预览找不到图片 | 检查对应文章的相对路径及实际文件；错误检查会区分缺失与暂无法读取 |
| 复制时图片读取失败 | 修复文件或权限后重试；准备失败不会被报告为整篇复制成功 |
| 改动后预览未更新 | 保存或点击更新样式，核对生成状态和格式报告 |
| 外部改文稿后列表信息仍旧，或索引需要修复 | 主动扫描并重建对应月索引；不要根据不完整索引判断文章已丢失 |
| 格式配置报错 | 按 FORMAT.md 修复整套配置，再保存草稿并重新打开资料库；缺文件或旧格式不会与默认文件混配 |
| 主题 JSON 导入失败 | 检查两类主题格式、字段、ID／文件名及同名冲突，参见 THEME.md |
| 公众号接收效果不同 | 核对微信草稿和手机预览；先用已测范围的写法，并查看格式报告 |

## 🧭 支持范围

Node.js 24 为 [官方 LTS 分支](https://nodejs.org/en/about/previous-releases)。本轮验证环境及通过范围见交付回执；不要把框架的最低 Node 版本当作全部测试工具的已验证版本。

- 常用 Markdown/GFM、受控 HTML、文章主题和 Tailwind 文章工具类。
- 整篇多图混排复制的公众号实验已在 macOS 接收方由用户验证；这不构成全部图片格式、浏览器或接收应用的兼容承诺。
- 微信公众号默认规范以[微信官方编辑器插件规范](https://developers.weixin.qq.com/doc/service/guide/product/plugin_spec.html)为依据。即时、布局／深色与人工核对分别报告；旧版格式分级和粘贴实测不作为本版官方合规证明。配置、来源、覆盖及迁移见[FORMAT.md](FORMAT.md)。
- 只读知识库、单篇 Markdown 导入和通用资源已纳入本版；公式/Mermaid按库可选启用。实际浏览器/接收方范围以验证记录为准。
- 同稿协作、公众号 API 与自动发布仍属范围外。
- 应用是单 Next.js 静态项目，没有业务后端、数据库或服务器端文章保存。静态服务只监听本机地址，不提供资料目录接口。
- 首次安装和构建需要取得依赖；页面及本地资源加载完成后的编辑／保存以本机文件为基础。不要把这一点解释为已提供离线安装包或完整 PWA 缓存。

## 🛠️ 开发与贡献

```sh
npm run dev
npm run typecheck
npm test
npm run build
```

`npm run dev` 默认使用 3500；使用前核对同端口服务，避免与日常静态服务冲突。依赖由 `package-lock.json` 固定，更新依赖时一并核对受影响范围；按锁文件复现依赖可用 `npm ci`。

反馈问题时提供应用版本、系统／浏览器、操作步骤、预期和实际结果；涉及资料时使用可分享的最小样例。贡献代码、主题或片段时先复现，再验证保存、预览与对应输出。真实目录权限、系统剪贴板和微信接收方检查分别记录，不能用自动测试代替。

当前代码源和版本见 [package.json](../../../package.json)，功能变化也可在应用版本按钮中查看。本项目采用 [MIT License](../../../LICENSE)。随附字体和第三方资源沿用各自许可，详见原资源文件与包信息；GitHub 仓库及远端推送由维护者确认。
