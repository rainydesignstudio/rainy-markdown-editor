## ✨ 功能与特性

| 功能 | 说明 |
|---|---|
| 🗂️ **外置资料库** | 编辑器主题、文章主题、片段、起稿模板、文章、历史记录，甚至是格式清单、校验和排版策略，都按资料库解耦，一个资料库就是另一个世界。 |
| 💾 **纯本地管理** | 文章资料在本机浏览器中处理，即使通过在线页面使用，管理的也是你自己的本地资料库。 |
| 👁️ **真渲染预览** | 左侧写源码，右侧看预览；预览、复制与可视导出共用渲染和格式处理流程，排版与图片都能先在本地核对。 |
| 🎨 **主题自定义** | 编辑器主题控制工作台外观；文章主题控制正文排版，支持浅色和深色预览。 |
| 🧩 **模板随心建** | 用起稿模板组织文章，用片段复用提示卡、章节等内容，后者只要在文中输入 `//` 即可快捷插入。 |
| 🗃️ **分组与归档** | 按项目、分类和年月整理文章，支持归档、Fork 和历史快照，还可为文章设置分类，方便二级查找。 |
| 🖼️ **内置素材库** | 统一管理共享/文章图片与附件：类型筛选、搜索、排序、多选、移动/复制、改名、描述和删除；图片保留替换、缩放预览。 |
| ⚙️ **外置检测器** | 每个资料库独立保存格式规范、校验与渲染策略，可通过配置文件或自主渲染包定制，无须修改应用。 |
| ✅ **格式检查** | 在撰写时提示格式和本地图片问题；保存与复制前仍会提供独立检查结果，方便查看哪里还要改。 |
| 🌐 **中英界面** | 切换语言保留草稿、查找替换和已有报告；日期、数量与公告按界面语言显示，资料库内容保持原文。 |
| 📦 **文档导出** | 保存文稿，导出文档包、Markdown、长图片或 PDF；完整原稿可保留元数据和未保存修改；渲染失败时仍可下载。具体入口以应用中的导出菜单为准。 |
| 🔗 **只读知识库** | 连接多个只读知识源，支持检索、图谱、专题书架、摘录与引用、来源变化核对，也可导入可编辑副本。 |
| 📥 **Markdown 导入** | 主题预选可换，正文先建档、资源后台复制，支持暂停、重试与补选。 |
| 🧮 **公式与图** | 可选本地公式/静态 Mermaid 渲染，源码保持，输出按目标平台核对。 |

内置多套文章主题和编辑器主题，公众号预设还提供二十多个片段和多份起稿模板。你也可以从空库开始，按需定制。

在文稿信息中修改目录名后，点击“保存文章”与其他修改一并保存。中文及全角标点按输入保留；路径分隔符、保留字符和重名会被拒绝。界面显示新目录名，正文文件仍叫 `article.md`。

本地图片“查看与改名”窗口用普通滚轮上下看长图，Ctrl/⌘＋滚轮缩放；图片框底部居中按钮可缩小、放大或恢复适应宽度。

<a name="doc-run-yourself"></a>

### 💻 自己启动

准备 Git、Node.js 24 LTS（含 npm）和桌面浏览器。本项目统一使用 npm，依赖由 `package-lock.json` 固定。浏览器需要提供 File System Access 目录授权能力，桌面 Chrome／Edge 是应用建议入口。其它系统／浏览器组合的实际目录和剪贴板行为需自行确认。

获得源码后，在项目目录安装依赖、构建并启动：

```sh
npm ci
npm run build
npm start
```

打开终端打印的本机地址，并保持服务运行。

默认地址为 `http://127.0.0.1:3500`。需要其它端口时用 `npm start -- --port 3501`（替换为已确认端口）；启动帮助用 `npm start -- --help`。端口占用时服务退出，不会自动结束已有进程。

构建完成后，日常在同一项目目录执行 `npm start` 即可启动。源码更新后重新安装所需依赖、构建并刷新浏览器；启动脚本有变化或服务仍使用旧目录时，再重启服务。

更新主题或资料库配置后，先点“更新样式”，再复制到剪贴板接收区和目标平台核对。用于微信公众号时，还需手动检查草稿和手机预览。详细配置见[复制输出配置](FORMAT.md#doc-copy-output)。

<a name="doc-font-downloads"></a>

### 字体下载与离线使用

在“设置 → 本地目录 → 字体下载来源”中选择来源；连接或创建资料库前也能设置。默认 Google Fonts，国内可选免费“国内镜像（JSDMirror）”，无需购买 CDN。偏好保存在当前浏览器来源内，不按语言或地区自动切换。

首次使用时会下载缺失的 Sen、Noto Sans SC、Roboto Mono 字体，已有字体和自定义文件不会被覆盖。下载失败时先用系统字体，不影响载入资料库；可在同一区域点“补充缺失字体”，或换源后重试，也可取消下载。

字体保存在资料库后可离线读取。补充字体时，浏览器需要能访问 `raw.githubusercontent.com` 或 `cdn.jsdmirror.com`；下载直接访问所选来源，不经过官网服务器。字体来源与许可见 [字体来源清单](../../../resources/font-sources.json)。

<a name="doc-first-use"></a>

## 🌱 第一次使用

1. 打开“设置 → 本地目录 → 新建资料库”，输入资料库文件夹名称，选择校验与算法模板（“微信公众号”或“空校验器”），然后选择父目录并授权读写。应用会创建一个命名子目录；同名目录已存在时，请改名或使用“打开已有资料库”。
2. 已有资料库直接使用“打开已有资料库”，选择资料库本身。应用只记住最后一个目录书签；权限失效时需重新授权。
3. 新建文章，输入正文并保存（macOS `⌘S`，其它系统 `Ctrl+S`）。文章目录和主题快照在保存时生成。
4. 在“主题”中试看文章主题。已保存文章使用“复制并应用”，生成副本并保留原稿和主题快照；未保存新稿使用“应用到当前稿”。
5. 在“模板”中管理片段和起稿模板；在编辑器里通过“插入元素”或输入片段触发词采用。
6. 在“素材”中导入共享/文章图片与附件。也可把本地文件拖入素材页，核对目标库、文件清单及格式后确认；取消不写入。采用共享图片会复制到文章自己的 `media/image/`；共享原件与文章副本独立。
7. 可选连接[只读知识源](#doc-knowledge)，主动扫描后浏览、搜索或从图谱打开文档。
8. 可选[导入 Markdown](#doc-markdown-import)，正文先建档，资源在后台取得；失败项在任务窗恢复。
9. 复制富文本，先在剪贴板接收区核对，再到目标平台粘贴检查；用于微信公众号时，由使用者手动粘贴，并检查草稿和手机预览。 接收区使用当前资料库的浅色纸面，保留粘贴内容原色；文章深色预览不改变这里的底板。

窗口窄时可切换源码／预览。目录授权、素材操作和公众号编辑以桌面浏览器为主要使用场景。

<a name="doc-preview-controls"></a>

### 👁️ 文章预览操作

预览标题栏的三个图标从左至右如下，悬停或键盘聚焦可查看提示；偏好按浏览器来源记住。

| 控件 | 默认 | 行为 |
|---|---|---|
| 预览滚动对齐 | 关闭 | 源码顶端对应的已渲染元素对齐预览顶部；只从源码联动预览。 |
| 保存时显示格式检查 | 开启 | 手动保存后显示报告；关闭只省略弹窗，自动保存不弹窗。 |
| 仅保存时刷新预览 | 关闭 | 编辑时保留可见正文、主题及样式；成功保存编译后刷新，显式采用不同或更新后的主题成功时也刷新一次；开启时源码底部显示“保存刷新预览”，关闭恢复实时。 |

冻结画面不替代当前稿检查、复制或导出。留存画面也能滚动联动：仅对齐仍可对应的内容，插删处采用最近有效节点，没有对应节点时保留位置；复制若沿既有流程先保存未保存稿件，也会刷新画面。格式检查、原文保存和渲染记录失败分别反馈，不把留存画面或未完成检查视为通过。

新资料库自动保存默认关闭，已有显式设置保持。离开编辑页后暂停自动保存和自动快照，返回后遵循原开关；手动保存及未保存提醒保持。

预览深浅色开关位于三个预览操作按钮左侧，三个按钮的顺序保持。

<a name="doc-source-formatting"></a>

### ⌨️ 行内格式快捷键

在文章正文源码中按 `Cmd/Ctrl + B`、`Cmd/Ctrl + I`、`Cmd/Ctrl + U`，分别加粗、斜体和下划线；“插入元素 → 文字格式”右侧显示相同键位。选中文字会保留选区内容，空选区只插入成对标记；再次执行可取消直接包围选区的标记。普通Markdown使用对应Markdown标记，HTML段落文字使用HTML行内标签。

菜单和快捷键共用一次可撤销编辑，撤销/重做仍按当前输入框的焦点区分。输入法组合、只读或不可编辑状态不执行格式操作，查找/替换框的文字不会被改写。

图片地址为空或链接/解码失败会明确报错；已失败图片不再重复等待超时。加载中的资源仍不算检查通过，修复后点击格式检查重检。

<a name="doc-interface-language"></a>

### 🌐 界面语言

左侧栏底部可切换“简体中文”或“English”。首次按浏览器语言匹配，未匹配时使用英语；手动选择按当前浏览器地址记住。新资料库采用创建时的界面语言，之后切换界面语言不会翻译已有资料、改写文章或改变文章排版。

### 🗃️ 文章列表、分类与检查

全部文章、未分组与项目显示未归档文章；归档单独显示。分类来自当前集合。

“检查当前范围”检查当前搜索、年月及分类筛选后的文章，可查看进度或取消。汇总按篇计数；未检测、需重检和检查失败分别显示。列表显示上次检查结果，修改正文、主题或格式配置后需重新检查。

分类标签位于列表标题旁，点击筛选，再次点击取消；超过五个时从“更多标签”展开。多选图标用于选择文章，再批量调整项目或归档；归档列表可批量取消归档或删除。

外部直接修改文章后，如列表信息未同步，请主动扫描并重建对应年月的索引。普通“刷新”不会重新扫描全部正文。列表提示索引异常或内容不完整时，按页面提示重建，原稿及损坏文章的诊断会保留。

<a name="doc-knowledge"></a>

## 🔗 只读知识库

1. 先连接可读写的文稿资料库，再在“知识库 → 添加知识源”选择独立目录，仅申请读取。两个目录不能相同或互相包含。
2. 首次点“扫描更新”，改动原文件后再次扫描；扫描后仍未显示最新内容时，可用“强制重建”。扫描失败或取消保留上次完整结果；页面会提示缺失、歧义或未完成的内容。
3. 可读 Markdown 链接和 `[[路径或唯一文件名|别名]]`；代码、公式和 Mermaid 源码中的示例不计关系。全局/局部图支持筛选、定位、拖动和缩放，双击节点或 Enter 打开只读文档。
4. 选中文档点“生成文章”，创建可编辑副本并选文章主题。知识源始终只读；导入资源、索引和任务记录都写到文稿资料库。

同一文稿资料库可连接多个只读知识源，各源独立扫描和检索。大图裁切时可筛选或改用局部图。索引包含可搜索的源文内容，随文稿资料库备份；知识原件需另行备份。

搜索框填关键词，可展开短语、排除词、标题及路径条件。同段命中优先，多段结果按资料折叠。阅读区可跳标题/段落、打开资料链接并返回原处；编辑页右侧“资料参照”为轻量浏览与阅读区域：按知识源浏览自适应文档卡片，点击后阅读全文，通过面包屑返回原列表和读位。参照栏位于文章预览上方，可折叠，并可拖动中间分隔条调整高度。管理知识源、扫描、图谱和专题等完整功能仍从知识库页面进入。

采用选段默认插普通正文和`[n]`，引用块按需选择；也可为已有论述补引用。引用条目完全自由，元数据缺失不阻断；可主动复用，点击正文编号开小窗或在文末直接改。只在点击“整理编号”时重排并清除未用条目。选中旧标记后，须在引用弹窗明确勾选替换选项才纳入管理；补引用默认保留正文选区并在末尾追加标记，其余旧引用／脚注保持。新稿来源快照在首次保存后登记。

“书架”中可独立创建专题，关联文章、收集整篇或选段、排序和备注。保留收集时文字，不搬动原件。“引用”显示原有入/出链的原句与位置，并可转到图谱。“变化”主动核对本地原文；缺失或变化显示标记，差异窗口可调整失配段落行号，由作者更新保留快照，文章正文不自动改写。

浏览器书签丢失时，重新定位原知识源可保留来源身份、索引、专题与引用；明确更换知识源需另行确认，并建立新的来源身份。

<a name="doc-markdown-import"></a>

## 📥 导入 Markdown 与资源

在文章页点“导入 Markdown”，选择 UTF-8 的 `.md` 或 `.markdown` 文件（上限2MiB）。默认选中资料库的文章主题，也可另选；导入会创建独立文稿和主题快照，保留原始文件。

需要连同本地图片或附件导入时，请在导入窗口另选源目录并授权读取；仅选 Markdown 文件不能读取相邻资源。导入保留原文件，资源会复制到新文章。网络资源可能因站点权限或访问限制下载失败，可补选本地文件。

正文中的图片、音视频资源和明确附件链接可随文稿复制；普通网页、其它笔记、样式中的背景图片与字体，以及复杂嵌入不会自动迁移，未迁移项会提示。保存了资源不代表目标平台支持显示，请核对实际效果。

<a name="doc-import-tasks"></a>

### ⏳ 后台任务与恢复

- 正文先出现，编辑、撤销和保存可继续；资源在后台复制并显示进度，后到的资源不会覆盖你的修改。
- “导入任务”可查看失败原因、暂停/取消、重试、补选源文件/源目录或替代资源。同库切稿继续，切库/失权暂停，删除目标取消；关闭页面后不继续运行，重开后需手动重试，可能从头下载。
- 恢复会核对来源、目标和已有文件。无法确认的同名文件保留并报冲突，不覆盖；新选择的替代资源会记录来源。任务记录保存失败时保留已建文稿并提示重试。
- 图片和附件可在素材库筛选、搜索、采用和下载。一般附件上限64MiB，图片按支持的格式和大小限制导入；受支持的图片可直接预览，SVG、PDF、音视频等附件不自动预览或执行。
- 拖入/选择文件先确认文件清单和目标，取消不写入。采用共享素材会复制独立文稿资源；改名更新当前引用并保留历史所需原件，删除前核对引用。资源卡片与详情显示引用状态；“移动或复制”保留被正文、历史或共享位置引用的原件，未引用资源执行移动。引用状态未知时暂不可执行，操作前再次核对；多选模式可按Esc退出。
- 校验区分导入中、失败和缺失，未完成不算通过。导出的文档包携带文章媒体及明确引用的共享资源，不包含知识源索引、来源缓存或导入任务；部分资源无法带出时会先征求确认，原引用保持。内存打包上限256MB。

<a name="doc-math-diagrams"></a>

## 🧮 公式与 Mermaid

随附渲染包可按资料库配置启用公式与 Mermaid；旧库及未启用的配置保持原行为。自定义渲染包以其实现和声明为准。启用方式见 [FORMAT.md](FORMAT.md#doc-source-rendering) 的示例。

公式支持行内 `$x^2$`、块公式和 `math` 代码块。Mermaid 支持流程、时序、状态、类和实体关系图，以静态图片呈现，不执行配置指令、交互或外部资源。原始源码保留，写法有误时会提示原因。

公式与图生成完成后再复制或导出，原文仍可先保存。粘贴后请核对目标平台的显示效果，必要时改用 PNG 或 PDF。

<a name="doc-trash-and-resume"></a>

### 文章回收与刷新恢复

设置→自动保存包含自动保存、历史快照和文章回收站三张卡片。回收站默认启用；关闭后的表单值保留，依赖控件禁用，保存后策略才生效。启用时删除文章完整移入`_trash/`，通知提供10秒撤销，之后仍可从文章侧栏的回收站恢复。停用后的永久删除须明确确认，无法撤销，旧回收内容仍可恢复。

清理垃圾先显示范围警告，确认后有30秒可撤回；撤回仅还原到回收站，期满才永久清理。通知关闭或切页不提前销毁，刷新／重开核对权限后接续剩余时间，浏览器关闭时不后台清理。原路径占用或写入失败会保留数据并报告，回收站不能替代独立备份。

操作通知在切换页面后保留；悬停、键盘聚焦、展开详情或执行操作时暂停自动消失计时。仍未解除的重要问题会保留提示，解除后才可关闭。

刷新编辑器恢复本页签、同一资料库中当前文章的已保存内容；设置／列表等页面保持原页。未保存改动仍使用离开提醒，不缓存未提交正文。详见[Agent指南](AGENT-GUIDE.md#doc-knowledge-workflow)及[记录契约](FORMAT.md#文章回收记录)。

载入过程、正常恢复及自动保存和自动快照成功不重复弹出通知。载入失败在当前载入位置显示原因及恢复操作；其他真实失败保留具体原因与恢复入口。

<a name="doc-faq"></a>

## ❓ 常见问题

| 现象 | 处理 |
|---|---|
| 启动端口占用 | 换一个已确认可用的端口，或由使用者处理已有服务；不要自动结束不明进程 |
| 界面仍是旧版本 | 源码更新后重新构建并刷新浏览器；仍连接旧目录的服务时，再重启该服务 |
| 目录权限失效 | 在“设置 → 本地目录”重新打开原资料库并授权 |
| 切换端口后找不到已记住的资料库 | 不同地址属于不同浏览器来源，需重新选择目录；磁盘文件仍在 |
| 源码有图片引用，预览找不到图片 | 检查对应文章的相对路径及实际文件；错误检查会区分缺失与暂无法读取 |
| 复制时图片读取失败 | 修复文件或权限后重试；准备失败不会被报告为整篇复制成功 |
| 改动后预览未更新 | 先检查“仅保存时刷新预览”是否开启，再保存或按需更新样式，并核对生成状态和格式报告 |
| 外部改文稿后列表信息仍旧，或索引需要修复 | 主动扫描并重建对应月索引；不要根据不完整索引判断文章已丢失 |
| 格式配置报错 | 按 FORMAT.md 修复整套配置；自主渲染包还需同步文件校验值，再点“设置 → 本地目录 → 重新加载渲染配置”。缺文件或坏配置不会与默认文件混配 |
| 主题 JSON 导入失败 | 检查两类主题格式、字段、ID／文件名及同名冲突，参见 THEME.md |
| 公众号接收效果不同 | 核对微信草稿和手机预览；先用已测范围的写法，并查看格式报告 |

<a name="doc-support"></a>

## 🧭 支持范围

Node.js 24 为 [官方 LTS 分支](https://nodejs.org/en/about/previous-releases)，安装与开发以该分支为基准。

- 常用 Markdown/GFM、受控 HTML、文章主题和 Tailwind 文章工具类。
- 整篇多图混排复制的公众号实验已在 macOS 接收方由用户验证；这不构成全部图片格式、浏览器或接收应用的兼容承诺。
- 微信公众号默认规范以[微信官方编辑器插件规范](https://developers.weixin.qq.com/doc/service/guide/product/plugin_spec.html)为依据，检查以当前资料库配置为准；实际接收效果仍需核对草稿与手机预览。配置与自定义方法见[FORMAT.md](FORMAT.md)。
- 支持只读知识库、单篇 Markdown 导入和通用资源；公式/Mermaid按库可选启用，目标平台的接收效果需实际核对。
- 容量限制：知识库每源最多索引10000篇文档，单篇上限2MiB；图谱最多显示300节点／2000连线，裁切后可筛选或使用局部图。
- 同稿协作、公众号 API 与自动发布仍属范围外。
- 应用是单 Next.js 静态项目，没有业务后端、数据库或服务器端文章保存。静态服务只监听本机地址，不提供资料目录接口。
- 首次安装和构建需要取得依赖；页面及本地资源加载完成后的编辑／保存以本机文件为基础。不要把这一点解释为已提供离线安装包或完整 PWA 缓存。
