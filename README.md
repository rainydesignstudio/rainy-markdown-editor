## ✨ 功能与特性 / Features

| 功能 / Feature | 说明 / Description |
|---|---|
| 🗂️ 本地资料库 / Local libraries | 文稿、主题、素材与历史保存在授权目录。<br />Keep manuscripts, themes, assets and history in your authorized directory. |
| 👁️ 写作与预览 / Writing and previews | Markdown＋HTML 实时排版，配套格式检查与导出。<br />Live Markdown + HTML layouts, format checks and export. |
| 🧩 主题与模板 / Themes and templates | 自定义编辑器与文章主题，用片段和起稿模板组织内容。<br />Customize both theme types and compose with snippets and starter templates. |
| ⚙️ 格式策略 / Format policies | 每库使用自己的 format-support、validator 与 formatter。<br />Each library has its own support rules, validator and formatter. |
| 🖼️ 文稿与素材管理 / Article and asset management | 分组、分类、归档、历史对照，以及图片预览和批量管理。<br />Groups, categories, archives, history comparisons and image management. |
| 🌐 中英界面 / Chinese and English | 切语保留草稿与查找状态，用户内容保持原文。<br />Switch languages while preserving drafts, find state and original content. |
